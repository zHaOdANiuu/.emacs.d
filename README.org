  *Elegant Emacs* is a personal Emacs 30+ config — no framework, no bloat.

* Features

  - *Fast startup* — GC tuning, JIT lock optimization, deferred autoloads, suppressed redisplay during init
  - *One-key workflow* — =<f1>= format, =<f2>= rename, =<f5>= debug, =<f12>= jump, =C-c s= search
  - *Custom dark theme* — ~nn-world~, =M-x nn-world-reload= to iterate live
  - *=HOME=* dashboard — recent files, todo, quick actions; =n/p= navigate, =C-<f1>= summon
  - *Completion* — Corfu or completion-preview; fido-frame child-frame minibuffer
  - *LSP* — Eglot on demand via context menu; =<f2>= rename, =<f12>= jump
  - *Visual debugger* — Dape + GDB, floating toolbar, breakpoints, process attach
  - *Git* — Magit, VC, ediff, and automatic smerge conflict detection
  - *Formatting* — Apheleia with prettier, clang-format, and shfmt; =<f1>= formats the buffer
  - *Search* — ripgrep powers grep / xref / project; =C-c s= searches the current directory, wgrep edits results
  - *Terminal anywhere* — Ghostel popup (=C-`=), Eshell, and MSYS2 auto-detection
  - *Translation* — =C-c t w/r/b= for word / region / buffer; also available from the context menu
  - *Mode-line* — cached Git branch, diagnostics, LSP status, encoding, and line-ending information
  - *Batteries included* — EWW, ERC, Newsticker, Gnus, proxy toggle, and right-click menus
